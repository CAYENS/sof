# Audio asset (no binary in repo)

This repository intentionally contains **no binary audio files**.

How to add your own track locally:
1. Put your file in this folder (for example `assets/audio/atmosphere.mp3`).
2. Set `invitationConfig.profile.musicPath` in `script.js` to that path.

Recommended track style:
- elegant dark ambient / neoclassical / cinematic
- volume-normalized, no clipping
- smooth intro (or keep fade-in in `script.js`)
